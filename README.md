## 📖 Описание

**AutoRent Pro + DriveControl** — это двухкомпонентная система для автоматизации работы пункта проката автомобилей:

- **AutoRent Pro** — десктопное приложение (PyQt6) для сотрудников компании
- **DriveControl** — веб-портал (FastAPI) для клиентов и администраторов

Оба приложения работают с **общей базой данных SQLite** (`rental.db`), что обеспечивает синхронизацию данных в реальном времени без дополнительных механизмов.

### Ключевые возможности

- 🚗 Управление автопарком с фотографиями
-  База клиентов с паспортными данными
- 📝 Оформление договоров аренды с автоматическим расчётом стоимости
- 💰 Учёт платежей и штрафов
- 🔧 Управление техническим обслуживанием
- 📅 Визуальный календарь бронирований (диаграмма Ганта)
- 📊 Статистика и отчёты (CSV, PDF)
-  Система уведомлений с автопроверкой
- 💬 Обращения в поддержку с перепиской
- 🔄 Запросы на возврат автомобилей
- 🛡️ Многоуровневая система прав доступа (RBAC)
-  Журнал аудита всех действий
- 💾 Автоматическое резервное копирование

### Синхронизация между компонентами

- **Фотографии автомобилей** автоматически синхронизируются между папками `images/` (СУ) и `static/car_images/` (веб)
- **Уведомления** создаются в СУ и отображаются в веб-портале
- **Обращения в поддержку** доступны из обоих интерфейсов
- **Запросы на возврат** инициируются клиентом через веб и обрабатываются админом в СУ

## ⚙️ Установка и запуск

### Требования

- Python 3.10 или выше
- pip (менеджер пакетов Python)
- Git (опционально)

### Шаг 1: Клонирование репозитория

```bash
git clone https://github.com/Xynary25/MTUCI-Car-Rental.git
cd MTUCI-Car-Rental
```

### Шаг 2: Создание виртуального окружения

```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# Linux/macOS
python3 -m venv .venv
source .venv/bin/activate
```

### Шаг 3: Установка зависимостей

```bash
pip install -r requirements.txt
```

### Шаг 4: Настройка переменных окружения

Скопируйте файл `.env.example` в `.env` и настройте параметры:

```bash
cp .env.example .env
```

Основные параметры:
- `DB_TYPE` — тип базы данных (`sqlite` или `postgresql`)
- `APP_ENV` — режим работы (`development` или `production`)
- `LOG_LEVEL` — уровень логирования (`INFO`, `DEBUG`, `WARNING`, `ERROR`)

### Шаг 5: Запуск десктопного приложения (AutoRent Pro)

```bash
python main.py
```

При первом запуске автоматически:
- Создастся база данных `rental.db`
- Создадутся тестовые пользователи
- Заполнятся тестовые данные (автомобили, клиенты)

### Шаг 6: Запуск веб-портала (DriveControl)

```bash
cd web_portal
python main.py
```

Веб-портал будет доступен по адресу:
- Главная страница: http://127.0.0.1:8000
- Админ-панель: http://127.0.0.1:8000/admin
- Управление автопарком: http://127.0.0.1:8000/admin/cars
- Консоль логов (только для админов): http://127.0.0.1:8000/admin/dev-logs

## 🎯 Функциональность

### Десктопное приложение (AutoRent Pro)

#### 📊 Дашборд
- Общее количество автомобилей в автопарке
- Количество активных договоров аренды
- Общее число зарегистрированных клиентов
- Выручка за текущий месяц
- Автообновление каждые 30 секунд

#### 🚗 Автопарк
- Просмотр списка всех автомобилей с характеристиками
- Поиск по марке, модели или гос. номеру
- Добавление нового автомобиля с загрузкой фотографии
- Редактирование данных автомобиля
- Удаление автомобиля из автопарка
- Двойной клик по строке — просмотр детальной карточки с фотографией
- Автоматическая загрузка фото по гос. номеру из папки `images/`

#### 👥 Клиенты
- Просмотр списка клиентов с паспортными данными
- Поиск по ФИО
- Добавление нового клиента с валидацией телефона и email
- Удаление клиента из базы
- Паспортные данные: серия, номер, дата и место выдачи

#### 📝 Договоры
- Создание нового договора аренды (выбор клиента, авто, дат)
- Автоматический расчёт стоимости на основе суточной ставки авто
- Скидки: 10% при аренде от 7 дней, 20% от 14 дней
- Проверка доступности автомобиля на запрашиваемые даты
- Завершение активного договора (автомобиль возвращается в доступные)
- Экспорт договоров в PDF (одним файлом или отдельными)
- Поиск по клиенту или автомобилю
- Ctrl+клик или Shift+клик для выбора нескольких договоров для массового экспорта

#### ⚠️ Штрафы
- Добавление штрафа к активному договору
- Типы штрафов: повреждение, просрочка возврата, курение, мойка и др.
- Отметка штрафа как оплаченного
- Отмена штрафа
- Удаление записи о штрафе
- Карточки статистики: всего штрафов, не оплачено, оплачено

####  Техническое обслуживание
- Добавление записи о ТО (плановое, сезонное, внеплановое)
- Указание пробега, стоимости, исполнителя
- Автоматическое планирование следующего ТО
- Отметка ТО как выполненного
- Отмена или удаление записи ТО
- Карточки статистики: всего записей, запланировано, выполнено

#### 🔔 Уведомления
- Автоматическая проверка каждые 5 минут
- Уведомления о предстоящих возвратах (за 1-3 дня)
- Уведомления о просроченных возвратах
- Уведомления о новых обращениях в поддержку
- Уведомления о запросах на возврат автомобилей
- Цветовая индикация приоритета (критический, высокий, средний)
- Отметка уведомлений как прочитанных
- Быстрый переход к договору/обращению по клику
- Кнопка «Написать пользователю» для ответа клиенту
- Индивидуальные уведомления для каждого пользователя

#### 📅 Календарь
- Визуальное представление бронирований в виде диаграммы Ганта
- Выбор периода отображения
- Цветовое кодирование: синий — активный договор, зелёный — завершён
- Отображение записей ТО (жёлтый — запланировано, зелёный — выполнено)
- Наведение на полосу — всплывающая подсказка с деталями
- Клик по полосе — открытие полной информации

#### 📈 Статистика
- Учёт расходов и ремонтов (таблица с фильтрацией)
- Топ-5 популярных автомобилей по количеству аренд и доходу
- Добавление новых расходов (ремонт, страховка, прочее)
- Сортировка топа: сначала по количеству аренд, затем по доходу

#### 📑 Отчёты
- Экспорт реестра договоров аренды в CSV
- Экспорт финансовой статистики за период:
  - Общие доходы и расходы
  - Чистая прибыль
  - Топ-10 автомобилей по доходности
  - Расходы по типам
- Файлы сохраняются в кодировке UTF-8 с BOM для корректного отображения кириллицы в MS Excel

#### 🛡️ Безопасность и управление БД
- Просмотр журнала всех действий пользователей (аудит)
- Создание резервной копии БД
- Создание пустой БД (только структура таблиц)
- Создание БД с тестовыми данными
- Восстановление БД из резервной копии
- Удаление БД (с двойным подтверждением)

#### ⚙️ Настройки
- Размер шрифта (10-20pt)
- Тип базы данных (SQLite/PostgreSQL)
- Путь для резервных копий
- Автоматическое резервное копирование:
  - Частота (ежечасно, ежедневно, еженедельно, ежемесячно)

##  Роли и права доступа

В системе реализована многоуровневая система прав доступа (RBAC). Каждая роль имеет определённый набор прав, которые можно индивидуально настраивать.

### 👑 Главный Администратор (superadmin)

Неизменяемая роль с максимальными привилегиями. Не может быть удалена или деактивирована.

**Права:**
- ✓ Полный доступ ко всем разделам системы
- ✓ Создание/редактирование/удаление любых пользователей (кроме себя)
- ✓ Назначение любых прав и ролей
- ✓ Управление базой данных (создание, удаление, восстановление)
- ✓ Просмотр журнала аудита всех действий
- ✓ Доступ к настройкам системы
- ✓ Экспорт любых отчётов
- ✓ Доступ к консоли разработчика
- ⚠️ Нельзя изменить свои данные или деактивировать себя

### 🔧 Администратор (admin)

Полный доступ ко всем функциям системы с некоторыми ограничениями.

**Права:**
- ✓ Полный доступ ко всем разделам (кроме управления супер-админом)
- ✓ Создание/редактирование/удаление пользователей (кроме superadmin)
- ✓ Назначение ролей и прав (кроме роли superadmin)
- ✓ Управление резервным копированием
- ✓ Просмотр журнала аудита
- ✓ Доступ к настройкам приложения
- ✓ Экспорт отчётов и статистики
- ✓ Доступ к консоли разработчика
- ✗ НЕ может удалять или редактировать superadmin
- ✗ НЕ может назначать роль superadmin

### 👨‍💼 Менеджер (manager)

Управление основными бизнес-процессами: клиентами, автомобилями, договорами.

**Права:**
- ✓ Просмотр дашборда и статистики
- ✓ Полный CRUD для автомобилей, клиентов, договоров
- ✓ Управление штрафами и ТО
- ✓ Экспорт договоров и отчётов
- ✓ Просмотр календаря бронирований
- ✗ НЕ имеет доступа к журналу аудита
- ✗ НЕ может управлять пользователями
- ✗ НЕ имеет доступа к настройкам БД
- ✗ НЕ может создавать резервные копии

###  Оператор (operator)

Минимальные права для оформления договоров и просмотра информации.

**Права:**
- ✓ Просмотр дашборда
- ✓ Просмотр автопарка, клиентов, договоров
- ✓ Создание новых договоров аренды
- ✓ Просмотр уведомлений
- ✓ Смена собственного пароля
- ✗ НЕ может создавать/редактировать автомобили
- ✗ НЕ может создавать/редактировать клиентов
- ✗ НЕ имеет доступа к статистике и отчётам
- ✗ НЕ может управлять штрафами и ТО (только просмотр)
- ✗ НЕ имеет доступа к настройкам

### Миграция на PostgreSQL

Для многопользовательского режима рекомендуется миграция на PostgreSQL:

1. Установите PostgreSQL 14+
2. Создайте базу данных:
   ```sql
   CREATE DATABASE rental_db;
   CREATE USER rental_user WITH PASSWORD 'secure_password_2026';
   GRANT ALL PRIVILEGES ON DATABASE rental_db TO rental_user;
   ```
3. Измените в `.env`:
   ```env
   DB_TYPE=postgresql
   POSTGRES_URL=postgresql://rental_user:secure_password_2026@localhost:5432/rental_db
   ```
4. Запустите миграцию:
   ```bash
   python utils/db_migrate.py
   ```

## 🔒 Безопасность

### Хеширование паролей

- Алгоритм: SHA-256 с индивидуальной солью
- Соль генерируется случайно для каждого пользователя
- Пароли никогда не хранятся в открытом виде

### Защита сессий

- HTTP-only cookies для веб-портала
- Автоматический таймаут сессии (настраивается)
- Проверка прав доступа на каждом endpoint

### Журнал аудита

Все действия пользователей записываются в таблицу `audit_logs`:
- Вход/выход из системы
- Создание/редактирование/удаление записей
- Изменение настроек
- Операции с базой данных
